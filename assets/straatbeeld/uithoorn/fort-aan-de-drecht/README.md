# Fort aan de Drecht — BoRacer Asset Pack

This package contains game-ready reference assets for **Fort aan de Drecht** in Uithoorn.

## Included
- 5 view images (`front`, `back`, `left`, `right`, `top`) — 1024×1024 PNG
- 1 line-art reference — 1024×1024 PNG (+ SVG wrapper)
- 4 material/detail textures — 512×512 PNG
- `manifest.json` with file descriptions and scale status
- preview image and original AI reference sheet

## Recommended modeling approach
- Treat the fort as a **low, elongated ring-like fortification on an island**, surrounded by a moat.
- Keep the **bridge and gate** as the primary readable entrance silhouette.
- The right-side/rounded bunker form should be modeled as a distinct protruding volume.
- Use the top view to block out the island footprint first, then add walls, openings and roof berm.
- Favor recognizability and gameplay readability over exact architectural fidelity.

## Scale
No verified real-world dimensions are included in this pack. Use approximate game scale or look up exact dimensions separately if needed.

All files use the prefix `fort_aan_de_drecht_`.
