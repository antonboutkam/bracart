# Thamerkerk — BoRacer Asset Pack

This package contains game-ready reference assets for **Thamerkerk** in Uithoorn.

## Included
- 5 view images (`front`, `back`, `left`, `right`, `top`) — 1024×1024 PNG
- 1 line-art reference — 1024×1024 PNG (+ SVG wrapper)
- 4 material/detail textures — 512×512 PNG
- `manifest.json` with file descriptions and indicative game-scale dimensions
- preview image and original AI reference sheet
- 5 original source photos

## Recommended modeling approach
- Start with a simple blockout: a compact rectangular brick church volume with a hipped roof.
- Add the **white portico** at the main entrance and the **octagonal white cupola tower** centered on the ridge.
- Keep the arched windows readable and evenly spaced; they define the character of the side elevations.
- Prioritize recognizability and clean gameplay-friendly silhouette over strict architectural precision.

## Scale
Indicative modeling dimensions in `manifest.json`:
- width: about **22 m**
- depth: about **17 m**
- main roof height: about **14 m**
- total height with cupola: about **23 m**

These are visual estimates for game use, not official measurements.
